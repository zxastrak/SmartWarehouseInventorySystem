# SUSUNO MOBILE APP

Proyek aplikasi mobile ini dikembangkan untuk memenuhi tugas mata kuliah Mobile Development (Tugas #9 - Local Storage & Data Persistence).

## 🚀 Fitur & Implementasi Teknis (Tugas #9)
- **Database Lokal (Drift):** Mengimplementasikan penyimpanan data terstruktur secara *offline-first* dengan penanda waktu (*UTC millis*) dan reaktif (`.watch()`).
- **Pengaturan (Shared Preferences):** Digunakan untuk menyimpan preferensi dan konfigurasi aplikasi yang berukuran kecil dan non-sensitif.
- **Keamanan (Flutter Secure Storage):** Menyimpan data rahasia seperti *access token* dan kredensial pengguna secara aman dan terisolasi.
